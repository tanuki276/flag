# Asteria — Astral Duelist

ブラウザで動作するオリジナルのアニメ調ファンタジー3Dキャラクター試作です。Three.js を使い、GitHub Pages で静的ホスティングできるようビルド工程なしの単一 HTML にまとめています。

## Live demo
GitHub Pages の初回デプロイ完了後、通常は https://tanuki276.github.io/flag/ で公開されます。

## 操作
- ドラッグ：カメラ回転
- ホイール：ズーム
- POSE：ポーズ切り替え
- BURST または Space：アストラルエフェクト
- RESET VIEW：視点リセット

Three.js は jsDelivr CDN から読み込みます。公開にはインターネット接続が必要です。本作は特定ゲームのキャラクターやアセットを複製しないオリジナルの試作です。
